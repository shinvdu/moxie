# 常见问题

## 使用

**Q：孩子端输入绑定码提示「绑定码无效或已使用」？**

绑定码只能用一次，且 5 分钟过期。回家长端点「绑定平板」重新生成。

**Q：孩子端提示「该设备尚未绑定」或跳回绑定界面？**

家长点过「解绑」，或者换了设备。重新走一次绑定流程。

**Q：点了「下一个」没声音？**

第一次必须点「**开始默写**」按钮——浏览器规定没有真实点击不允许出声。另外检查平板音量与静音键。

**Q：孩子端显示「出了点小问题」？**

网络断了。检查 WiFi，点「重试」。音频在页面加载时已预加载，短暂断网通常不影响已开始的默写。

**Q：家长下发后孩子平板没更新？**

在孩子平板上刷新页面（下拉刷新或关掉重开）。主屏幕图标的话，长按图标重新打开。

**Q：每次下发都显示「复用 38 段、新增 0 段」正常吗？**

正常，而且是好事。音频按内容寻址，这些词已经生成过，直接复用。换新课文时才会有「新增」。

**Q：为什么孩子端看不到词语？**

这是刻意的。孩子端 API 从服务端就不下发词面，只有音频路径，打开开发者工具也看不到。答案只在全部默写完成后才可查看。

**Q：忘记密码？**

当前没有找回功能，只能换手机号重新注册。产品化前需要补短信 / 邮箱重置。

**Q：孩子一路点「下一个」点到最后看答案怎么办？**

工具只能保证「答案不在默写过程中出现」，不能判断孩子是否认真写。这需要家长监督。

**Q：能同时录多课的词吗？**

可以，一次下发多课的词即可。但别一次太多，孩子一次写不完。

## 部署

**Q：为什么必须用 musl 静态链接？**

Lambda AL2023 的 glibc 版本可能低于构建机，动态链接会报 `GLIBC_2.xx not found`。`deploy.sh` 默认使用 `x86_64-unknown-linux-musl`。

**Q：部署时提示 AWS 凭证未设置？**

确认 `.env` 放在仓库根目录，格式参考 `.env.example`。`deploy.sh` 会从 `infra → moxie → apps → 仓库根` 往上找 `.env`。

**Q：CloudFront 自定义头 / JWT 到不了 Lambda？**

`/api/*` 必须挂 `b689b0a8-53d0-40ab-baf2-68738e2966ac`（AllViewerExceptHostHeader）OriginRequestPolicy，否则 `X-Authorization` / `X-Device-Token` 会被丢弃。

**Q：POST 请求返回 403？**

缺少 `x-amz-content-sha256` 头。前端必须对 body 做 SHA-256 并带上十六进制结果。

**Q：访问 `/health` 返回 403？**

CloudFront 只把 `/api/*` 路由到 Lambda，裸路径会落到 S3。用 `/api/health`。

**Q：Lambda 调用 CloudFront 时 403 AccessDeniedException？**

OAC 需要两条 Lambda 权限：`lambda:InvokeFunctionUrl` 和 `lambda:InvokeFunction`。模板已包含，检查是否被删除。

**Q：拍照上传报 413？**

CloudFront 请求体上限约 1.5–2MB。手机原图必须先在浏览器用 canvas 压缩到长边 ≤1600px（项目里的 `parent.html` 已实现）。这不是优化，是必需步骤。

**Q：删除栈时卡在 DELETE_FAILED？**

S3 桶非空，或前端桶有历史版本。先清空桶（包括所有版本）再删栈。

**Q：换区域后部署失败？**

Lambda Web Adapter Layer ARN 是分区域的。修改 `params.json` 的 `WebAdapterLayerArn`，并确保 `.env` 的 `AWS_DEFAULT_REGION` 一致。

**Q：自定义域名 HTTPS 到期？**

CloudFront 用的是导入 ACM 的证书副本，acme.sh 续期不会自动同步。确认 `--install-cert --reloadcmd` 钩子调用了 `renew-acm.sh`，或手动跑一次。证书必须位于 `us-east-1`。

**Q：为什么不用 ACM 自带的 DNS 验证？**

部分 DNS 服务商的 CNAME 记录拒绝以下划线开头的值，而 ACM 验证要求 `_xxxx.acm-validations.aws.`。改用 Let's Encrypt 的 DNS-01（TXT 记录）更稳。

## 发音与 OCR

**Q：多音字读错了怎么办？**

在家长端点「改拼音」，用数字声调（1/2/3/4/0），音节空格分隔。例如：

| 词 | 拼音 |
|---|---|
| 模糊 | `mo2 hu2` |
| 模仿 | `mo2 fang3` |
| 谈吐 | `tan2 tu3` |
| 糊涂 | `hu2 tu0`（轻声） |
| 熟悉 | `shu2 xi1` |

保存后会生成新的内容寻址音频，不会影响旧缓存。

**Q：第 2 课《繁星》需要补拼音吗？**

不需要。已人工逐词试听，Polly 默认读法全部正确，包括 5 个多音字风险词。样本见 `samples/pronunciation/`。

**Q：怎么确认 Polly 的拼音 SSML 真的生效？**

同一文本用不同拼音生成的 MP3 哈希不同。实测「模糊」无标注 / `mo2 hu2` / `mu2 hu2` 三者哈希都不同。

**Q：OCR 总是不可用？**

默认走 GLM-4V，需要 SSM 参数 `/<project>/<env>/zhipu_api_key`。若账号未开通 Bedrock，配置 `OPERON_MOXIE_BEDROCK_MODEL_ID` 也不会生效。拍照不可用时仍可用「粘贴文本」录入。

**Q：OCR 认错词 / 只认出每行第一个词？**

提示词必须明确「一个格子里可能有多个词语」并举例。代码中已内置这条约束，修改提示词后请跑测试（`prompt_demands_all_words_from_each_cell`）。

**Q：免费 OCR 模型能用吗？**

实测 `glm-4v-flash` 在同一张生字表上只有 14/19，还会出现「谈吐 → 谈话」这类错字。默认使用 `glm-4v-plus`（19/19，约 2.5 秒）。

**Q：OCR 结果里混进了拼音？**

解析器只保留**含汉字**的 token。带声调的拼音（`fán` 里的 `á`）不是 ASCII，早期用 ASCII 过滤会漏掉，现已修复并有回归测试。

## 设计与限制

**Q：为什么孩子端不自动播下一个？**

这是产品的核心差异。固定间隔自动播无法适配不同孩子的书写速度。手动推进把节奏交给孩子，也让家长不必守在旁边。

**Q：为什么音频不经过 Lambda？**

Lambda Function URL 有 6MB payload 上限，且没有二进制响应接口。音频走 CloudFront → S3 直连，既避上限也让分发成本趋近零。

**Q：为什么每个词生成两个音频文件？**

念一遍 / 念两遍。两遍版用 SSML `<break>` 分隔，比客户端连播两次停顿更自然。孩子端切换遍数只是换 URL，无延迟。

**Q：为什么设备令牌不用 JWT？**

JWT 签发后在过期前无法撤销；家长解绑时需要旧令牌**立刻**失效。所以使用不透明随机令牌，服务端只存 SHA-256。

**Q：一个账号能有几个孩子？**

数据模型支持多个（`USER#{user_id}#KIDS` 分区下多条 `KID#`）。当前前端也支持添加多个孩子。

**Q：能防得住孩子看源码吗？**

孩子端页面源码里没有词面，API 响应里也没有。音频文件名只是哈希。除非孩子能访问家长账号或直接猜出音频内容，否则看不到词。

**Q：为什么不用短信验证码 / 限流？**

当前是家庭自用定位，优先简单。产品化前必须补，见 [安全设计](security.md#四已知缺口产品化前必须补)。
