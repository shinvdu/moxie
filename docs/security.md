# 安全设计

moxie 处理的是家庭账号与儿童学习数据。本文说明威胁模型、当前保证、实现方式，以及**尚未做**的部分。请不要把当前版本当作面向公众的产品直接上线。

## 一、资产与威胁模型

| 资产 | 风险 |
|---|---|
| 家长密码 | 撞库、明文泄露 |
| 孩子的词表 / 答案 | 被其他账号越权读取；被孩子自己偷看 |
| 设备令牌 | 平板丢失后无法撤销 |
| 绑定码 | 被暴力猜解、被重放 |
| 音频 URL | 被热链、产生流量费 |
| AWS 凭证 / SSM 密钥 | 泄露 |

假设攻击者可以：

- 注册自己的账号并正常使用 API；
- 查看浏览器开发者工具与网络响应；
- 知道其他账号的 `kid_id`（UUID 不应当被当作秘密）；
- 在公网发起暴力尝试。

## 二、当前的安全保证

### 1. 多租户隔离（最重要）

所有家长端 `{kid_id}` 操作都先经过 `owned_kid()`：

```rust
// 按当前登录用户的 user_id 拼分区键
db.get::<Kid>(&Kid::pk_for(user_id), &Kid::sk_for(kid_id))
```

孩子记录存在 `pk = USER#{user_id}#KIDS` 下。**别人的 kid_id 拼不出自己的分区，自然取不到**。

返回统一 `404 孩子不存在`，不区分「不存在」与「不属于你」，避免攻击者枚举 `kid_id` 是否存在。

覆盖测试：

- 用 A 的 JWT 读取 / 下发 / 生成绑定码 B 的孩子 → 404；
- 账号与孩子分区必须不同（防止 `query()` 反序列化冲突）；
- 不同账号的同名 `kid_id` 设备令牌互相解析不到对方分区。

### 2. 防偷看：孩子端拿不到词面

`GET /api/kid/current` 的响应结构里**根本没有 `text` / `pinyin` / `title`**：

```json
{
  "total": 19,
  "default_repeat": 1,
  "items": [{ "a1": "/audio/....mp3", "a2": "/audio/....mp3" }]
}
```

词面只在默写结束后的 `/api/kid/answers` 返回。用户即使打开开发者工具，网络响应里也没有任何汉字。

**为什么连标题也不下发**：标题形如「第2课《繁星》」，而「繁星」本身就是待默写的词。这是实施中发现并修复的真实泄露点。

测试强制检查：

- 用真实词表构造会话，响应 JSON 不含任何汉字（`\u{4E00}..\u{9FFF}`）；
- 不含 `text` / `pinyin` / `title` 字段；
- 答案接口在结束后**应该**包含词语。

### 3. 密码

- 使用 **argon2id**（当前密码哈希推荐算法），每次 16 字节随机盐；
- 哈希串格式为 `$argon2...`，绝不含明文；
- 长度 6–128 字符；
- 哈希串损坏时 `verify_password` 返回 `false`，不 panic、不泄露内部状态；
- 登录失败统一返回「手机号或密码不正确」，不暴露手机号是否注册；
- 日志不打印密码。

### 4. 设备令牌可撤销

令牌格式：`{user_id}.{kid_id}.{32 字节随机 hex}`。

- 前两段是 UUID，用于定位记录，不是秘密；
- 真正的凭证是最后 32 字节随机数；
- 服务端只存它的 **SHA-256**，使用 `subtle::ConstantTimeEq` 做常量时间比较；
- 家长点「解绑」清空哈希后，旧令牌**立即失效**。

**为什么不用 JWT 做设备令牌**：JWT 无状态，签发后在过期前无法撤销。平板丢失 / 换设备时，需要立刻让旧凭证失效。

### 5. 绑定码

- 6 位，字符集去掉了易混的 `0/O/1/I/L`；
- 5 分钟有效；
- **无论校验是否通过，读取后立即删除**——同一个码不能重放；
- 校验归属后再写设备令牌哈希。

测试覆盖：绑定码长度 / 字符集 / 无易混字符；解析器拒绝垃圾输入；令牌哈希稳定且不包含原令牌。

### 6. 音频不可猜

音频 key：`audio/{sha256(text|pinyin|repeat|voice)[:16]}.mp3`。

文件名是 16 位哈希，无法从词语直接猜出；内容哈希变化（例如改拼音）会产生新文件，不会污染旧缓存。

### 7. 网关层

- Lambda Function URL 使用 `AWS_IAM`，只允许 CloudFront OAC 调用；
- 两条 Lambda 权限（`InvokeFunctionUrl` + `InvokeFunction`）都配置；
- S3 桶全部 Block Public Access，仅通过 bucket policy 授信对应 CloudFront OAC；
- API 请求经 CloudFront 时必须带 `x-amz-content-sha256`；
- 业务 JWT 走 `X-Authorization`，避免与 OAC 的 SigV4 `Authorization` 冲突。

### 8. 输入校验

| 项 | 规则 |
|---|---|
| 手机号 | 11 位、以 1 开头、纯数字 |
| 密码 | 6–128 字符 |
| 孩子姓名 | 非空、≤20 字 |
| 年级 | 1–12 |
| 词语 | trim 后非空、≤30 字、不含控制字符 |
| 词表 | 非空、≤200 词 |
| 图片 | base64 可解码、非空、解码后 ≤4MB |
| 设备令牌 | 三段格式、随机段 64 hex |

## 三、端到端验证

`apps/moxie/verify.py` 在部署后运行 59 项断言，安全相关包括：

| 断言 | 预期 |
|---|---|
| 孩子端会话不含任何汉字（逐词 + 整体） | ✓ |
| 他人 JWT 读 / 下发 / 生成绑定码该孩子 | 404 |
| 绑定码重放 | 400 |
| 解绑后旧设备令牌 | 401 |
| 无凭证访问家长接口 | 401 |
| 重复下发命中缓存（`generated=0`） | ✓ |
| 音频 `Content-Type` 与 MP3 魔数 | ✓ |

```bash
python3 apps/moxie/verify.py https://<your-cloudfront-domain>
```

## 四、已知缺口（产品化前必须补）

| 缺口 | 风险 | 建议 |
|---|---|---|
| **无速率限制** | 注册、登录、绑定码可被爆破 / 刷接口 | CloudFront WAF rate-based rule，或应用层按 IP / 手机号限流 |
| **手机号未验证** | 任何人可用任意格式合法的手机号注册 | 接入短信验证码 |
| **无密码找回** | 忘记密码只能换号 | 短信 / 邮箱重置流程 |
| **音频 URL 可热链** | 流量费 | CloudFront 签名 URL / Cookie |
| **孩子端无额外 PIN** | 拿到平板的人可打开已绑定页面 | 可选：解锁 PIN 或家长临时授权 |
| **绑定码在线爆破** | 6 位字符集约 8.9 亿组合，5 分钟窗口 | 限流 + 失败次数锁定 |
| **无审计日志** | 异常行为难追溯 | 结构化安全事件日志 + 告警 |
| **SSM 密钥轮换无自动流程** | JWT 种子泄露后影响面大 | 定期轮换流程（轮换后所有家长需重新登录） |

## 五、部署侧建议

- 使用独立的 IAM 用户 / Role 部署，遵循最小权限；
- `.env` 不入库（已在 `.gitignore`），不要提交任何 `password.txt` / 密钥文件；
- 生产环境开启 CloudTrail、CloudWatch 告警与 AWS Budgets；
- DynamoDB 已开启 PITR；前端桶开了版本控制；
- 定期检查 CloudFront / ACM 证书到期时间，确认续期钩子生效。
