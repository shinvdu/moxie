# 使用说明

> 面向家长和孩子。网址以你自己的部署为准，例如 `https://moxie.example.com`。
>
> moxie 专门解决一件事：**每报一个词，等小朋友写完，再报下一个**——不用家长在旁边一直念。

## 一、它解决什么问题

以前：家长拿着词语表念，念一个等孩子写完再念下一个。孩子写得慢的时候，一课要十几分钟，每天重复。

现在：家长在**自己手机**上把词语录进去，点「下发」。孩子在**平板上**点一下就能开始，程序一个一个念，孩子写完点一下屏幕，念下一个。**家长不用守在旁边。**

两个特点：

- **不是固定间隔自动播。** 网上多数听写 App 是「每 20 秒自动报下一个」，写得快的小孩干等，写得慢的跟不上。这个是**纯手动**——孩子写完才点。
- **屏幕上不显示词语。** 孩子端从头到尾只有按钮和进度，看不到任何汉字，没法照着抄。

## 二、需要准备什么

| | |
|---|---|
| 家长手机 | 任意浏览器（微信里打开也行） |
| 孩子平板 | Android 平板，推荐 Chrome 或夸克 |

不需要装 App、不需要上架应用商店。音频在家长下发时已经生成好，孩子端不依赖实时合成。

## 三、第一次使用（约 5 分钟）

### 第 1 步：家长手机注册

1. 打开 `https://<你的域名>/parent.html`；
2. 点「注册」→ 填**手机号（11 位）**、**密码**（至少 6 位）、确认密码，昵称可填可不填；
3. 点「注册并登录」。

> 密码目前没有找回功能，建议记在常用的地方。

### 第 2 步：添加孩子

1. 点右上角「**+ 添加孩子**」；
2. 填名字（比如「小明」）、年级 → 点「确定添加」。

### 第 3 步：绑定平板

1. 在孩子那一行点「**绑定平板**」；
2. 屏幕上出现一个 **6 位绑定码**（比如 `G926KX`），下面写着「5 分钟内有效」；
3. 拿起孩子的平板：
   - 打开 `https://<你的域名>/child.html`；
   - 输入这 6 位码 → 点「**绑 定**」。

> 绑定码**只能用一次**，而且 **5 分钟就过期**。过期了就在家长端点一次「绑定平板」重新生成。

### 第 4 步：把图标放到孩子平板上（强烈建议）

绑定成功后，在平板浏览器的菜单里选「**添加到主屏幕**」。

之后平板桌面上会多一个图标，**孩子点图标就能直接进默写界面**，不用再输绑定码。

## 四、每天怎么用

### 家长：三步

#### ① 录词

在家长端点开孩子 →「录入词表」，两种方式：

| 方式 | 怎么做 | 建议 |
|---|---|---|
| **粘贴文本** | 把词语粘进输入框 → 点「解析并填入」 | ⭐ 最可靠，推荐 |
| **拍照 / 相册** | 点「📷 拍照 / 从相册选择」拍老师发的词语表 → 自动识别 | 方便，但偶尔会认错，需检查 |

粘贴格式很随意：**每行一个词、一行多个词、空格 / 逗号 / 顿号分开都行**，程序会自动整理、去重。像「繁：繁星 繁华」这种带冒号的格式也认。

如果内容里有「第2课《繁星》」这样的标题行，可以勾上「**过滤标题行**」把它去掉。

#### ② 试听检查（重要，别跳过）

词表下方每个词旁边有「**▶ 试听**」，点一下听读得对不对。

- **读对了** → 不用管；
- **读错了** → 点「**改拼音**」，填上正确读音 → 点「保存并试听」。

拼音写法：**用数字标声调**（1 一声、2 二声、3 三声、4 四声、0 轻声），音节之间空格隔开。

| 词 | 拼音 | 说明 |
|---|---|---|
| 模糊 | `mo2 hu2` | 「模」读 mó，不是 mú |
| 糊涂 | `hu2 tu0` | 「涂」是轻声，用 0 |
| 谈吐 | `tan2 tu3` | 「吐」读 tǔ，不是 tù |
| 熟悉 | `shu2 xi1` | 教材标 shú，不是 shóu |

弹窗里有「常用词参考（点开）」，拿不准就点开看。

> 首课（第 2 课《繁星》）已人工试听验证，Polly 默认读音全部正确，不需要改拼音。

#### ③ 下发

点底部「**下发给孩子**」。会看到类似提示：

> 已下发：新增 0 段音频，复用 38 段

**「复用」多、「新增」少是好事**，说明这些词的音频之前已经生成好、可以直接用（同一课的词在所有用户之间共享）。只有**从没出现过的新词**才需要「新增」，几秒钟就好。

看到提示就成功了。**孩子平板上刷新一下**（或重新点开图标）即可开始。

### 孩子：四步

1. 点平板上的图标 → 点「**开始默写**」；
2. 听到一个词 → **在纸上写出来**；
3. 写完 → 点「**下一个**」（点屏幕任意地方也行）；
4. 全部写完 → 出现「完成！」→ 可以点「看答案」自己核对。

## 五、孩子端界面说明

```
┌─────────────────────────────┐
│                             │
│        第 3 / 19 个          │   ← 进度
│      ████████░░░░░░░░        │
│                             │
│    ┌───────────────────┐    │
│    │                   │    │
│    │     下一个         │    │   ← 最大，点屏幕任意处也等于按它
│    │                   │    │
│    └───────────────────┘    │
│                             │
│   ┌────────┐  ┌────────┐    │
│   │ 上一个  │  │  重读   │    │
│   └────────┘  └────────┘    │
│                             │
│      播报遍数  ① 遍  ② 遍     │   ← 孩子可随时切
└─────────────────────────────┘
```

| 按钮 | 作用 |
|---|---|
| **下一个** | 写完了，报下一个词 |
| **上一个** | 写错了想改，回到前一个词 |
| **重读** | 没听清，再念一遍当前这个词 |
| **① 遍 / ② 遍** | 一个词念一遍还是两遍。切换会**立刻重念当前词** |

**整屏都能点**，不一定要精准点到按钮上。平板接键盘的话：`空格` = 下一个，`←` = 上一个，`R` = 重读。

几个贴心的地方：

- **屏幕不会自动黑**——孩子写字时不会熄屏；
- **音频提前加载好了**——点「下一个」立刻出声；
- **看不到词语**——屏幕上只有按钮和「第 N / M 个」；
- **答案要点完才看得到**——「看答案」只在完成页出现。

## 六、家长端其他功能

| 功能 | 说明 |
|---|---|
| **标题（可选）** | 给这次默写起个名字，比如「第2课《繁星》」。**只给家长自己看**，孩子端不会显示（标题里常常含答案） |
| **播报遍数** | 设定默认念一遍还是两遍，孩子端仍可自己改 |
| **手动添加** | 词表下面也能一个一个手动加词 |
| **删除** | 每个词旁边有「删除」 |
| **解绑** | 换平板或平板丢了，点「解绑」，旧平板的令牌立刻失效 |

## 七、常见问题

**Q：孩子端点「绑定」提示「绑定码无效或已使用」**

绑定码只能用一次，且 5 分钟过期。回家长端点「绑定平板」重新生成一个。

**Q：孩子端提示「该设备尚未绑定」或跳回绑定界面**

家长点过「解绑」，或者换了设备。重新走一次绑定流程即可。

**Q：点了「下一个」没声音**

第一次必须点「**开始默写**」按钮——浏览器规定没有真实点击不允许出声。另外检查平板音量。

**Q：孩子端显示「出了点小问题」**

网络断了。检查 WiFi，点「重试」。

**Q：家长端下发后，孩子平板没更新**

在孩子平板上刷新页面（下拉刷新，或关掉重开）。主屏幕图标的话，长按图标重新打开。

**Q：每次下发都显示「复用 38 段、新增 0 段」，正常吗？**

正常，而且是好事。说明这些词的音频已经存在，直接复用。换新课文时才会有「新增」。

**Q：拍照识别不准**

换「粘贴文本」方式。拍照识别对图片质量有要求，光线暗、拍歪了、字太小都可能出错。

**Q：忘记密码了**

目前没有找回功能。换个手机号重新注册。

**Q：孩子不小心点到「看答案」怎么办？**

「看答案」只在全部默写完之后才出现。如果孩子一路点「下一个」点到最后再去看答案，那说明没有认真写，需要家长监督。

## 八、小技巧

- **家长手机也可以「添加到主屏幕」**，每天点开就录词；
- **一次可以录多课的词**，不用每天录。别一次搞太多，孩子写不完；
- **录完先试听一遍再下发**，比下发后发现问题再改省事；
- **词语表直接从微信复制粘贴**就行，程序会自己解析；
- **出门在外也能用**，家长手机和平板不必在同一个 WiFi 下。
