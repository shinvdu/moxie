# 发音校对样本

这些 MP3 由 AWS Polly（`cmn-CN` / Zhiyu / neural）在项目实施阶段生成，用于**人耳**核对多音字读音。语音识别工具无法判断「Polly 读得对不对」，这一步只能人工试听。

## 目录

```
00-全部19词连读.mp3          听整体节奏和连读效果
01-默认读音/                 19 个词逐个一个文件
02-多音字对照/               5 个高风险词，A = 默认读法，B = 拼音标注读法
```

### 多音字对照

| 词 | A：默认 | B：拼音标注 | 关注点 |
|---|---|---|---|
| 谈吐 | `谈吐-A默认.mp3` | `谈吐-B标注tan2tu3.mp3` | 「吐」读 tǔ，不是 tù |
| 模糊 | `模糊-A默认.mp3` | `模糊-B标注mo2hu2.mp3` | 「模」读 mó，不是 mú |
| 模仿 | `模仿-A默认.mp3` | `模仿-B标注mo2fang3.mp3` | 同上 |
| 糊涂 | `糊涂-A默认.mp3` | `糊涂-B标注hu2tu0.mp3` | 「涂」是轻声 |
| 熟悉 | `熟悉-A默认.mp3` | `熟悉-B标注shu2xi1.mp3` | 教材标 shú，不是 shóu |

## 结论（2026-09-29 人工试听）

**A 系列（Polly 默认读法）全部正确**，包括 5 个多音字风险词。因此首课不需要补任何拼音；B 系列作为「遇到读错时如何纠错」的对照手段保留。
